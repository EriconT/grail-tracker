Quick Setup Guide

  1. Go to GitHub Token Settings.
  2. Generate a classic token named "Grail Tracker" with the gist permission checked.
  3. Copy the token and paste it in the PAT field above.
  4. Click Create Private Gist for Me. The app will automatically create a secure repository for your collection and save the ID.
  5. Click Save Settings. You're fully synced! Load this app on your phone, paste the same PAT and Gist ID, and see your collection in real-time.
